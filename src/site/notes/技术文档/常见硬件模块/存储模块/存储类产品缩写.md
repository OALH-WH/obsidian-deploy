1. SROM（Static Read-Only Memory）

1. 定义：SRAM是一种静态只读存储器，非易失性存储器

1. 特点

1. 只读：内容在制造时就已经写入了，不可更改

1. 静态：不需要刷新操作来保持数据

1. 非易失：断电数据不丢失

1. SDRAM（Synchronous Dynamic Random-Access Memory）

1. 定义：同步动态随机访问存储器，一种易失性存储器

1. 特点

1. 动态：需要定期刷新来保持数据

2. 同步：操作与系统时钟同步                                                                                                                                                                                          
3. 易失性：断电数据丢失

4. SRAM

| 对比维度       | **SRAM (静态)**                      | **DRAM (动态)**                                |     |
| ---------- | ---------------------------------- | -------------------------------------------- | --- |
| **数据保持机制** | 使用 **触发器 (Flip-flop)** 锁存数据，不需要刷新。 | 使用 **电容 (Capacitor)** 存储电荷，电荷会泄漏，**需要周期刷新**。 |     |
| **速度**     | **极快**（纳秒级，与CPU寄存器速度接近）。           | **较慢**（几十纳秒，存在延迟）。                           |     |
| **集成度/容量** | **低**（结构复杂，占芯片面积大，片上只能放几MB）。       | **高**（结构简单，占芯片面积小，可以做到GB级别）。                 |     |
| **成本**     | **非常昂贵**（单位成本高）。                   | **相对便宜**（单位成本低）。                             |     |
| **功耗**     | 静态功耗低，但面积大导致总功耗不低。                 | 需要刷新电路，动态功耗较高，但单位容量功耗低。                      |     |
| **主要用 途**  | CPU 缓存 (Cache)、**片内嵌入式内存 (SRAM)**。 | 计算机主板上的**主内存 (DDR内存条/颗粒)**。                  |     |
