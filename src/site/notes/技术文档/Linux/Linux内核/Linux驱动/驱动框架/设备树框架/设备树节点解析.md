# 常用功能
## 子节点相关
### 遍历所有子节点
- `for_each_child_of_node()`: 宏定义, 实现为`for`循环头, 需自行补充循环体
	- `break`退出循环, 需要调用`of_node_put(child)`手动释放内存
- `for_each_child_of_node_scoped`: 自动释放引用的安全版本
### 只遍历`status = "okay"`的子节点
- `for_each_available_child_of_node()`
### 获取子节点数量
- `of_get_child_count()`
### 获取下一个子节点
- `of_get_next_child()`
