# mmc设备相关
## mmc

**位置参数**
- `info`
- `read`
- `write`
- `erase`
- `...`
### 示例
```shell
# 列出所有mmc设备
mmc list

# 查看当前激活的mmc设备, 之后，许多命令如果不带设备号参数，就会默认使用这个设备
mmc dev

# 切换激活的设备到mmc0
mmc dev 0

# 显示当前激活的mmc设备信息
mmc info
```
# 分区表相关
## part
### 基本格式
```shell
# part从1开始编号, eg. mmc 0:1
part uuid <interface> <dev>:<part>
    - print partition UUID
part uuid <interface> <dev>:<part> <varname>
    - set environment variable to partition UUID
part list <interface> <dev>
    - print a device's partition table
part list <interface> <dev> [flags] <varname>
    - set environment variable to the list of partitions
      flags can be -bootable (list only bootable partitions)
part start <interface> <dev> <part> <varname>
    - set environment variable to the start of the partition (in blocks)
part size <interface> <dev> <part> <varname>
    - set environment variable to the size of the partition (in blocks)
```
### 示例
```shell
# 查看mmc0上的所有分区
part list mmc 0
```
# 引导内核相关
## `boot`
- 默认执行`bootcmd`中指定的命令
## bootm
从内存中解析内核镜像和设备树并启动内核
### bootm 引导 FIT 的 5 条核心规则
1. **寻址规则**：`bootm` 后第一个参数必须是 FIT 镜像在内存中的起始地址（如 `bootm 0x20000000`）。
2. **语法与优先级规则**：
    - 用 **`#`** 指定配置：`bootm <addr>#<config>`（自动加载套餐）。
    - 用 **`:`** 指定子镜像：`bootm <addr>:<subimg>`（只取特定数据块）。
    - **同时指定时，`#` 配置优先**，会忽略手动指定的子镜像参数。
3. **依赖加载规则**：
    - **指定配置**：自动根据配置节点引用，将内核、FDT、ramdisk 全部载入预设内存，**无需**额外参数。
    - **指定子镜像**：仅加载该组件（如内核）。若需启动 Linux，**必须**在命令后手动补充 FDT 地址（即 `bootm <addr> <ramdisk_addr> <fdt_addr>`），否则内核因找不到设备树而直接崩溃。
4. **安全校验规则**：
    - **指定配置**：校验配置节点下所有组件的**组合签名**（确保内核+设备树完全匹配）。
    - **指定子镜像**：只校验该子镜像自身的哈希值，不校验其他组件，存在“拼凑启动”的风险。
5. **默认行为规则**：若仅输入 `bootm <addr>` 且不带任何 `#` 或 `:`，则自动寻找 FIT 内 `default = "xxx";` 属性指定的默认配置来启动
### 示例
```shell
# 引导uboot可识别的内核镜像(uImage)和设备树
fatload mmc 0 0x3000000 uImage
fatload mmc 0 0x2A00000 devicetree.dtb
bootm 0x3000000 - 0x2A00000

# 引导FIT镜像, 包括内核镜像和设备树

## 当只有一个默认配置时
bootm <FIT ADDRESS>

```

## 加载文件到内存
## load命令
### 基本格式
`load <interface> [<dev[:part]> [<addr> [<filename> [bytes [pos]]]]]`
各个参数的含义是：
- **`<interface>`**：**必需**。指定存储设备的接口类型，例如 `mmc`、`sata`、`scsi`、`usb` 等
- **`[<dev[:part]>]`**：**可选**。指定**设备编号**和**分区号**
    - `dev`：设备编号，从0开始。
    - `part`：分区号，如不指定则默认为0（表示整个设备）
- **`[<addr>]`**：**可选**。指定文件在内存中的**加载地址
    - 如果不指定，会使用环境变量 `loadaddr` 的值；若 `loadaddr` 未设置，则使用默认配置 `CONFIG_SYS_LOAD_ADDR`
- **`[<filename>]`**：**可选**。要加载的**文件路径和名称
    - 如果不指定，会使用环境变量 `bootfile` 的值
- **`[bytes]`**：**可选**。要加载的**最大字节数**（十六进制）
- **`[pos]`**：**可选**。从文件开头**跳过的字节数**（十六进制），然后开始加载

**示例**
```shell
load mmc 0:1 10000000 u-boot-rockchip.bin
```
